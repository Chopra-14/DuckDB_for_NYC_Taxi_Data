# Pipeline DBT DuckDB

This repository contains a data pipeline built with **dbt** (data build tool) and **DuckDB** as the execution engine.

## Overview

- **dbt_project.yml** – dbt project configuration.
- **profiles.yml** – dbt profile pointing to a DuckDB database.
- **models/** – dbt model SQL files, including staging, intermediate, and mart layers.
- **data/** – Sample data (e.g., `yellow_tripdata.parquet`).
- **Dockerfile** & **docker-compose.yml** – Container setup for reproducible runs.

## Getting Started

1. **Install dependencies**
   ```bash
   pip install dbt-duckdb   # or your preferred method
   ```

2. **Run the dbt models**
   ```bash
   dbt run
   ```
   This will execute the SQL models against the DuckDB database and materialize the results.

3. **View logs**
   The `logs/dbt.log` file contains the output from dbt runs.
